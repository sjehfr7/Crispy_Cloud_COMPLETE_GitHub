# Crispy Cloud E-Commerce Website

Complete GitHub-ready static e-commerce website for Crispy Cloud.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `assets/` containing the Crispy Cloud logo and all 7 product images:
  - Strawberry Cream
  - Chocolate Cream
  - Matcha Cream
  - Crème Brûlée
  - Mango Cream
  - Yema Cream
  - Ube Cream

## Upload to GitHub
Upload **everything inside this folder**, including the entire `assets` folder. Do not upload only the HTML/CSS/JS files.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

This is a front-end prototype. It does not process real payments or save orders to a database.
